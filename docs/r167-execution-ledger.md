## 实现

- 当前工作区实际基线为 0.12.31（工单写作时为 0.12.30），本单源码版本升至 0.12.32。
- 选人阶段的推荐面板「详情」页签顶部新增「对位克制建议」。只在本人位置已知、敌方同位置英雄已锁定时渲染。普通排位的 `isAlly` 只标记本人，敌方的 `false` 还会被 `omitempty` 省略；因此按非己方判断，并比较双方 `teamId`，避免把己方队友当作敌人。

- 本人尚无明确英雄时，用敌方英雄 ID、本人分路和本人 `rank.tier` 请求现有 `/api/champions/detail?mode=ranked`；未提供段位时使用接口支持的 `all`，不猜测段位。取敌方视角 `counters.weakAgainst` 的前五位作为我方候选；卡片的“胜率差”是 `50% - 敌方对位胜率`，只显示真实小于 50% 的结果。
- 请求以敌方英雄 ID 和分路为本局缓存键，在发起前先占位，轮询期间不重复请求；敌方换位造成对位英雄变化时按新映射发一次。本人预览英雄后候选卡让位于本人对位数据；选人结束或切换对局时清空缓存。没有新增后端接口或上游请求路径。
- UI 只展示头像、英雄名、胜率和胜率差，没有加入统计口径说明。
