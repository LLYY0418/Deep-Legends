## 网络层更正

默认 Python User-Agent 的直连和中转响应均为 Cloudflare `403`、`text/plain`、`error code: 1010`，不是 Riot 的 Forbidden JSON，也没有 CONNECT tunnel failed 或 proxy 403 证据。网络代理环境变量均未设置。相同 Key 换 Mozilla/5.0 User-Agent 后直连和中转均 200，采集已恢复。此前“Key 无效”的判断撤回。

已保存去 Key 的完整响应头：[403 层诊断](history/reports/r211/network-layer-probe.json)、[同 Key 浏览器 UA 200 对照](history/reports/r211/network-browser-ua-probe.json)。因此校准项由“网络不可达，待确认”更新为“网络已恢复、真实评估未达标”，门槛未放宽。采集脚本可在用户本机运行，不在聊天中或报告中输出 Key。
