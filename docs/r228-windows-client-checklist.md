# R228：0.12.74 Windows 真机检查清单

0.12.74已于2026-10-06正式发布为Latest，key mode public。请通过客户端检查更新或下载正式安装包，再按本清单验收。CI合成接口、Windows安装升级不替代下面的真实游戏客户端检查。验收结果均未填写为通过。

复现后，在「设置 → 诊断与日志」点击「导出诊断日志」。每组记录开始/结束时间、客户端大区、版本/构建指纹、操作和结果，配对应截图；不要提交账号密码、客户端令牌或个人Key。诊断事件只用于排查，下面不要求填写个人Key内容。

1. **国服优先。** 登录真实国服账号，打开总览，检查最近20场、赛季统计及一场详情的所有玩家。分别截图并导出诊断。若不足20场，记录实际可用场次；不能把空列表算通过。若仍全空，保留完整导出日志，单独新开工单，不能回头覆盖R223结论；核对 `sgp_game_decode_failed` 的 `field/value_type/count` 及请求成功/失败事件，不猜测事故字段。
2. **日服与切换。** 日服登录后检查大区识别、本人战绩、外服分组及区服标签；切回国服再切日服，检查默认跟随、本人页签和总览是否正确更新。记录每次切换的截图与诊断时间。
3. **登录入口取消。** 客户端关闭时点击登录入口，在UAC提示点「否」。确认没有直接启动LeagueClient，入口仍可用，遮罩消失；随后正常启动。Riot客户端已经运行时点击入口，检查仅恢复/前置窗口，没有重复launch-product。分别导出日志。
4. **斗魂自动选用。** 勇敢举动分别试「立即锁定」和「亮出后锁定」，规划阶段不提前预选，本人回合执行并确认随机英雄。记录成功请求与 `write-result http-success` / `confirmation applied`。另试普通英雄预选失败后仍能锁定、禁用正常。分别暂停/恢复、手动接管/释放、关闭/打开总开关，恢复正常调度后不残留「自动选用已停止」。真正机会耗尽仍应提示停止；退出重进新会话清空旧状态。
5. **名单、排序与连续观察。** 先5v5再斗魂：当前18人、自己仅一条、英雄正确、三个MySquad成员在前；不能混入上一局teamTwo。峡谷、海斗、极地、斗魂、练习与当天其他轮换，每种连续观察3分钟，检查无整页闪烁、名字标签间距一致、本队/我的小队在前；保留重建/性能日志、截图及至少一分钟录像。若模式当天不可用，填写未测原因。
6. **客户端在线更新。** 正式Latest发布后，从0.12.73的「设置 → 检查更新」升到0.12.74。更新前后核对设置、Key已配置状态（不展示内容）、桌面快捷方式创建时间/目标与图标位置。记录安装8阶段及耗时、启动后的版本/指纹；CI升级0.12.65→0.12.68→0.12.74不能替代此用户机器升级。

结果表：每项填写「通过／失败／未测」、截图文件名、诊断日志文件名、时间范围。国服读取失败另开新工单；R223/R224的真机项目在取得证据前继续保留待验。
