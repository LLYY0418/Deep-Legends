Local-first · Windows desktop

Deep Legends

A free desktop companion for League of Legends. Browse Korean-server tier lists, runes and builds without opening the client, and review your own match history and collection once you're logged in locally — all processed on your own machine.

What it does

Two data paths, both read-only

For the Korean (KR) server, Deep Legends calls the official Riot Games API to look up a searched player's summoner profile, ranked tier and LP, champion mastery, and recent match history — then pairs that with champion tier lists, rune recommendations, and item builds drawn from Riot's public Data Dragon assets and community data.

For players logged into the Chinese (Tencent) client, the app instead reads profile, ranked, match history, live-game, and collection data directly from the player's own local League Client. This path never touches the Riot API.

Read-only by default

No account credentials are collected, no login is automated, and nothing is written back to Riot's servers. Optional client actions (a rune page, an item set) run only against the player's own local client, triggered by an explicit click.

Nothing leaves the machine

Data retrieved via the Riot API is never uploaded to a server the developer operates. Everything is processed and cached locally, and only salted, anonymized identifiers are ever written to local history files.

Fail closed on uncertainty

Where the data isn't verifiable — a stale endpoint, an ambiguous match, an unmapped item — the app shows a clear degraded state instead of guessing.
