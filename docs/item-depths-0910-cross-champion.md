# 第四、第五件装备：跨英雄核验（2026-09-10）

修复位于所有英雄共用的 `champions_structured.go`，没有英雄 ID、英雄名或分路白名单。首次根据凤凰日志修正了“第四、第五件必须同时存在，否则清空全部阶段”的条件；本次继续核验五个分路，并修复另外两条会丢失有效阶段的路径。

## 本次补充修复

1. HTML 内嵌 Flight 的解码不再依赖第四件行标记。只有第五／第六件的页面仍使用正确解码后的内容；此前会退回带转义的 HTML，导致有效行解析为零。
2. OP.GG 部分阶段解析失败时，按阶段保留其有效结果，QQ101 只补缺失阶段。此前 QQ101 只要返回任意阶段，就会整组覆盖 OP.GG，可能再次丢掉有效第四或第五件。
3. 补位后仍未取得的失败阶段继续标记不可用；记录具体失败阶段。混合来源标注为 `OP.GG + QQ101`，说明哪些阶段由 QQ101 补位，并保留较早的缓存取得时间。

正常缺样本不触发整组替换；空响应、404 页面、数据行存在但统计损坏，均不能当作正常“无样本”。现有核心装、零胜率和单场样本不受影响。
