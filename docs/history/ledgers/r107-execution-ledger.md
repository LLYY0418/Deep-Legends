# R107：9 月 18 日录屏及 09:38 日志复核

版本 0.12.4。保留原工作区 R95–R106 的修改。本轮材料：`钉钉录屏_2026-09-18 092347.mp4`（22.866 秒）、6 张截图、`lol-loot-diagnostics-0918-0938.jsonl`（1758 条有效记录）。附件仅作现象与诊断证据。

## 原因与改动

### 战绩图标和分页抖动

- R106 修复了无 src 图片被隐藏的问题，但冷图片仍只有 2 个并发，前端 3 秒、公开资源后端 2.5 秒即中止；底层图片传输还单独限制 3 秒。可见区域有大量图标时排队明显，慢请求过早失败。
- 更严重的是后端失败缓存 1 分钟，而前端 10 秒后就重试，重试仍得到缓存失败。现在并发 6、前端 10 秒，`/api/image`、`/api/champion-asset` 与底层传输统一 8 秒预算，失败缓存 5 秒。成功图片继续复用现有浏览器及磁盘缓存；失败图不会显示破图文字。
- 分页流的中间结果原来调用整页 rerender，导致旧卡片、顶部资料及侧栏图像重新创建。追加页现在只在完成后提交；补全结果保留未改变的卡片和统计节点。
- 历史段位 SSE 原来重新发起整个总览查询。后端现在在事件中带上段位，前端只更新同账号对应资料，不再重新请求整页。
- 保留 region/server/playerRef 隔离和详情修订号。复核时排除了“同分组不同玩家会复用旧列表”的误报：`matchTierScope` 本身包含完整玩家引用，列表还会按 gameId/数据差异协调。

### 职业账号的时间与排序

- R106 显示的 OP.GG `initUpdatedAt` 是资料刷新时间，不是开局时间。本轮改取身份核验后的 JSON-LD `PlayGameAction.startTime`，兼容韩文/空格的双重编码。
- 部分有段位账号的公开页面没有历史记录，此时才通过本项目 Riot 身份解析、最近一条 match ID、比赛 `gameStartTimestamp` 补齐。不复用 OP.GG PUUID，不额外查询段位，继续共用预留前台额度的限流器。
- 前端仅显示“最近对局”；删除“已检查”。每名选手下按真实开局时间倒序排列，不用查询时间填空。
- 活动时间显式写入公开快照，重启可恢复；有段位 15 分钟，明确未定级 72 小时；读取失败短暂退避，不把失败当作未定级。
- 实际联网读取固定 6 队/33 人/53 账号：47 有段位、6 未定级，47 个有段位账号全部取得开局时间，整批 11.52 秒；逐选手倒序校验通过。6 个未定级账号未取得历史记录，不编造时间，仍默认折叠。见 `r107-validation/live-profile-activity.log`。这是本机本次网络结果，不保证任意网络环境同样耗时。

### 生涯背景、头像、旗帜

- 日志 125 次背景状态中实际背景 ID 为 0；R106 却把目录第一款皮肤作为草稿，产生“寒冰情人节待应用”的假状态。现在 ID 为 0 时不创造待应用草稿，显示客户端默认背景；另增加当前 PUUID 的只读 profile 回查，能读到具体皮肤时同步展示。未获得具体 ID 时不假称已知道客户端默认原画。
- 头像 PUT 401 是实际拒绝；W5 的 201 属于已拥有头像探测，不能拿来证明未拥有生涯头像可用。新增 `/lol-chat/v1/me` 的 icon 回退，仅在写后回读一致时确认“聊天与好友栏头像”，不会替换生涯头像或冒充解锁。界面明确区分两个显示范围。参考实际开源实现：[league_profile_tool IconTab](https://github.com/lenny-ts/league_profile_tool/blob/main/src/components/tabs/IconTab.tsx)。
- 旗帜 W6 从已拥有物品中选取，PATCH 200 后立即读取 `changed:false`，所以“所有失败都因未拥有”缺乏依据。正式写入现在优先使用已拥有库存的 contentId，保留原始槽位 data 和数字精度；只读确认窗口由 0.6 秒增至 2 秒，不重复发送写请求。仍没变更时如实报告未确认。
- 复核排除了“LCU 字段改名”的误报：日志的 `item-ref/content-ref` 是 `r99SafeKey` 脱敏别名，实际协议仍为 `itemId/contentId`，不能据此修改请求字段。

**尚未证实**：当前 Windows 客户端是否接受未拥有旗帜、聊天头像回退是否在该客户端生效、默认盲僧原画是否能从新增 profile 读取。本机是 macOS，没有连接用户的 Windows LCU。不能承诺未拥有头像/旗帜已全面解锁，也不能把模拟接口测试当作真机成功。
