- 生涯缩略图大片空白时，日志没有对应规模的皮肤图片请求；只有 5 条远程资源失败（GTIMG 1、CommunityDragon 4）。不能用这 5 次失败解释整个皮肤网格和头像网格空白。代码同时存在头像选择器独立观察器、全局队列观察器和原生 lazy 三层调度，以及每次 DOM 变化都扫描全页面的问题。

- 1635 行正式选择旗帜 37 返回 HTTP 400。1794 行 W6 已拥有旗帜 4 返回 204，`changed:true`；该路径实际轮询 `summary.bannerId` 核对目标，随后 1797 行恢复返回 204。这证明普通装饰旗帜的 catalog ID 契约可工作，不能再把所有失败归为 ID 字段用错。
- 1793 行聚合的 HTTP 400，其 `window_start` 为 06:45:10，属于此前旗帜 37 的请求，不能误读成此次 W6 的 204 与 400 矛盾。
- 1766 行背景 136038 应用后，W5/W6 检测与恢复写入紧接着发生；1799–1805 行读取到背景 0、最高熟练度盲僧背景。旧检测包含真实装备写入，前端完成后还强制刷新、丢弃草稿，造成选择器回到首个英雄。日志不能进一步分离是哪一次客户端写入重置背景，但诊断不应执行这些写入。

## 修改

### 请求与限额

- 自动翻页要求新的向下操作；只进入视口、切换标签、恢复滚动位置不取下一批。后续页也必须重新获得操作意图，避免 10 场后自动连取 20 场。手动“加载更多”及按模式查询仍保留。
- 翻页执行前核对当前标签，清理观察器和输入监听器，防止旧标签继续请求。
- 增加 `riot_rate_policy`：只在收到有效限额头且策略变化时记录区域/接口族限额。`riot_local_rate_limited` 记录预算来源、窗口、使用预留量与 `upstream_429:false`，区分本地等待和上游 429。无响应头时生成的保守预算不伪装成上游策略。
- 匹配详情/时间线接口族对所有区域统一去除对局 ID。既有缓存、并发去重和响应头限额调度保留。

### 图片与页面稳定性

- 头像移除第二套观察器，只使用全局图片队列。队列按可视范围准入后改为 eager，避免已占名额的请求仍被原生 lazy 延后。
- DOM 变化只扫描新增子树或变化图片，取消每次变化全页扫描；离开可视范围的待发图片不抢占可见图片。
- 图片正在请求时切换了资源 URL，旧请求结束后立即继续新 URL，避免回退资源一直等不到下一次 DOM 事件。
- 生涯刷新失败保留当前背景、图片 DOM 和草稿。成功但未变化的状态仍复用原页面。上述变更减少无关重绘和图标重复调度。

### 检测与装备反馈

- “检测客户端支持”改为纯 GET 检查目录和拥有状态；不调用任何装备/恢复探测，不触发完成后的强制刷新，不改英雄选择、头像或背景。
- 被取消的旧生涯读取控制器立即清理，防止它阻挡之后的正常读取。
- 头像仍必须点击“设为头像”才写入；确认前显示拥有状态和可能生效的范围。
- 旗帜增加“已拥有”筛选及拥有状态说明。未拥有条目仍可尝试，失败保持选择器，不把请求受理或聊天头像变化当成生涯装备成功。

## 公开实现核查与功能结论

核查了以下原始项目与文档：

- [lcu-driver 的旧版隐藏头像示例](https://lcu-driver.readthedocs.io/en/latest/examples.html)：2020 年示例调用 `/lol-summoner/v1/current-summoner/icon`，使用 50–78 这组隐藏头像，201 表示写入被接受。不是当前任意未拥有头像的成功证据。
- [MManoah/lol-summoner-icon-changer](https://github.com/MManoah/lol-summoner-icon-changer)：2021 年归档的隐藏头像工具，不能证明 2026 客户端可以装备任意未拥有头像。
- [league-client-scripts/hide-banner.bat](https://github.com/nomi-san/league-client-scripts/blob/main/hide-banner.bat)：提交 `bannerAccent:"2"` 用于隐藏旗帜，不是解锁任意装饰旗帜。
- 本地此前保存的客户端 bundle `_saveIcon` 与 `_savePreferences` 使用同样的头像接口与 catalog banner ID，没有发现可据此替代的任意未拥有装备接口。

**可支持的结论：**已拥有装备有可用写入路径；本次未拥有头像只能确认聊天/好友栏变化，所选未拥有旗帜被拒绝。没有找到可复现的当前版本任意未拥有生涯头像/旗帜装备方法。因此不能承诺“像生涯背景一样任意切换”，也不能将这一点包装成已经修复。客户端版本、区域及具体物品仍可能存在差异。

Production Key 对多玩家冷开有帮助。[Riot 官方 Portal](https://developer.riotgames.com/docs/portal) 给出的 Personal 为 20 次/秒、100 次/两分钟，标准 Production 初始为 500 次/10 秒、30,000 次/10 分钟，按区域计算；代码以实际响应头为准，不能保证永不等待。
