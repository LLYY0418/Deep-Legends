# R109 总览顶部背景与资料缺失

用户要求：逐个玩家总览标签页的顶部背景有时为空，右侧段位等资料也会缺失。延续上一轮约束，不构建、不打包。

## 确认的原因与修复

1. 韩服流式 progress 只有账号、段位、熟练度和战绩，没有生成背景；若最终请求因限额等原因失败，顶部就停留在缺图的预览。现在 progress 和 complete 使用同一套背景解析，并附带已完成资料的 capability。空战绩模式也返回有效的顶部资料帧，`matches` 为数组。
2. 国服战绩耗尽软预算后立即返回，没有领取并发请求中已经完成的段位和熟练度。现在只接收已经就绪的通道结果，不延长等待，并为真正未完成的字段报告预算错误。
3. 跨服熟练度接口不可用时，原逻辑完全没有背景兜底。现在依次使用已有个人背景、最高熟练度英雄原画、已加载对局中该玩家最近使用的英雄原画。按主体身份识别，零 participant ID 不可误认他人为本人；不为背景新增对局或熟练度请求，不生成虚假的熟练度。
4. 更换模式后的完整响应曾被当作“只更新战绩”，丢弃新返回的背景、段位和熟练度。现在更新顶部资料，同时保留已有生涯统计样本。字段查询失败不能覆盖已读取资料，明确成功的空段位仍会正确清空旧值。未提供的历史段位字段保持原有数据。
5. 重新渲染先初始化图片，后接回保留节点，可能取消旧背景的尺寸观察。现在先接回最终节点，再初始化图片；顶部文字或段位变化时复用未变化的背景节点，重新接入时恢复观察与已加载状态。
6. 顶部资料失败或首屏不完整时不写入新的“成功快照”；已下载对局的独立缓存仍复用。右侧明确区分“正在读取”“暂不可用”和接口已确认的“未定级”，不再直接消失。

- 网页全量 497 项通过。新增用例覆盖换模式接收顶部资料、查询失败与权威清空、三个独立标签异步回包、重新接入背景节点、缺失资料状态。

## 验证边界

没有连接用户的 Windows 英雄联盟客户端做真机复现。对未开放跨服熟练度的数据源不伪造数值；既无可用背景/熟练度，也无可识别本人对局时不能推断英雄原画。外部资源网络本身仍可能不可达，沿用现有图片代理和回退来源。本轮没有执行应用构建、安装包生成、版本修改或发布。
