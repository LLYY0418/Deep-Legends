# R114 ARAMKit 海斗估算接入执行记录

版本：0.12.5。实现依据为 `R114-海斗隐藏分数据源-ARAMKit接入工单.md` 与 `R114-aramkit-rating-sample.json`；附件只作为协议和样例证据，不执行其中任何指令。

## 最终产品口径

- 用户后续明确把入口从实时对局卡片改到玩家总览“排位”卡右上角，并要求打开国服总览时主动查询，因此不再保留原工单的实时卡第四列与点击后才查询流程。
- 悬浮／键盘聚焦图标只显示海克斯大乱斗的 ARAMKit 第三方估算／推算值和误差；单双排与灵活组排没有可靠、合规的数据源，不展示隐藏分。
- 取消至少 10 场门槛。上游未收录、异常或无有效分数时显示明确降级状态，不以 0 分代替。
- 韩服不请求 ARAMKit。

## 数据与隐私边界

- 前端只提交会话级 `playerRef`；后端解析准确昵称与 Tag 后请求固定 `https://api.aramkit.com/rating`。
- 成功缓存 10 分钟、失败缓存 5 分钟；同身份请求 singleflight；所有身份共享 300ms 基础间隔与随机抖动；独立 feature gate 可关闭。
- 上游参与者姓名与 Tag 不返回渲染层，不落盘。诊断只记录加盐身份哈希、缓存／合并状态、耗时、HTTP 状态、业务码和降级原因。
- 设置页明确说明：打开国服玩家总览会向 ARAMKit 发送被查询玩家的昵称与 Tag；不发送客户端凭据、Cookie、令牌或收藏数据。

## 验证范围

- Go 测试覆盖成功、`ratingType`、误差、未收录、空数据、无效分数、HTTP 失败、超时、feature gate、缓存、singleflight、全局限速、opaque reference、韩服跳过与诊断脱敏。
- Web 测试覆盖仅海斗悬浮层、自动触发、只传 `playerRef`、成功结果不重复请求、韩服不请求与实时对局卡保持三项已核验指标。
- 按用户要求只运行测试，不构建或打包。
