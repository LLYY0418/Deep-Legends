## 0. 结论

1. **模块没有丢，是 tab 看不见。** 用户截图一显示：详情页的 概览/构筑/表现 三个 tab 和「海克斯图鉴」入口都在，所有改版前的模块都能点到。用户觉得"只剩几个模块"，是因为 `.mayhem-detail-tabs` 按钮只有 11px 字号、灰色文字、36px 高，缩在详情卡左下角，和上方醒目的"英雄榜/海克斯图鉴"大切换条形成反差，看起来不像可点的 tab。修复方向是改样式，不是加模块（§2.1）。前两版工单里的"版本落后""找回海克斯图鉴内嵌区块"两条作废。

4. 前两版里已经谈好的两项继续有效：该英雄专属品质概率挪到概览最下面；海克斯推荐标题行去掉"N 个"，阶段 tab 移到最右（§2.4）。海克斯推荐本身的实现保持现状。

## 2. 修复方向

### 2.1 概览/构筑/表现 tab 改成显眼的一级切换

目标：一眼能看出这是三页内容，而且不比上方"英雄榜/海克斯图鉴"弱太多。

- `.mayhem-detail-toolbar`：tab 组占满整行剩余宽度（`flex: 1 1 auto`），「海克斯图鉴」入口按钮保持在右侧。
- `.mayhem-detail-tabs`：改成 `display: grid; grid-template-columns: repeat(var(--tab-count),minmax(0,1fr))`（或 flex 等分），外框复用 `.mayhem-view-tabs` 的外观（`--surface` 底、1px 边、10px 圆角、4px 内边距）。
- 按钮：`min-height: 42px`、`font-size: 13px`、`font-weight: 750`；未选中 `color: var(--ink)` 的 70% 左右（不要用 `--muted`，太暗）；选中态与 `.mayhem-view-tabs button.is-active` 一致（`--primary-soft` 底 + 金色描边），再加一条 2px 金色底边或把文字换成 `--primary`，保证选中项一眼可辨。
- 窄屏（`champions.css` 现有 700px 断点）下按钮 44px 高，tab 组独占一行，图鉴入口换到下一行。
- 不新增任何说明文字或提示气泡。

### 2.2 表现指标重新排版

- **分组布局**：四个分组（战斗 KDA / 伤害输出 / 生存辅助 / 经济节奏）在宽屏下两列排布（`grid-template-columns: repeat(2,minmax(0,1fr))`），窄屏一列。每组内部从"五列小格"改成**逐行列表**：左边指标名，右边数值，数值下方或右侧是独立的"较平均 ±x%"小标签（单独一个元素，和数值之间有 6-8px 间距，字号比数值小一档）。这样每行只有一个指标，不会再出现"3.18较平均 -6.8%"粘在一起的情况。
- **多杀单独成行**：双杀/三杀/四杀/五杀四个累计项不再占四个格子，合并成战斗组里的一行"多杀累计"，四个数字横排（双杀 5,956,630 · 三杀 1,779,720 · 四杀 477,013 · 五杀 102,254），数值用 `--muted` 弱化，不带 ± 标签（现有逻辑已经不给累计项算 delta，保持）。"多杀指标 4.58 较平均 +73.3%" 保留为普通行。
- **删掉每格里的累计说明**：`champions.js:2250` 的 `<small>累计次数（…）</small>` 去掉。
- **说明挪到底部一次**：表现 tab 最底部（原统计口径页脚的位置）放一行小字：「双杀/三杀/四杀/五杀为累计次数，受出场场次影响，不可跨英雄直接比较。」只在表现 tab 显示，只在确实有累计项时显示。这是用户指定保留的唯一一句说明。
- **副标题**：删掉"赛后数据的每局均值，「较平均」是相对全部英雄同一项均值的百分比差"这句 `<p>`，只留标题"表现指标"和右侧"对比 173 位英雄"。
- CSS 对应修改 `champions.css:961-971` 一段；`.mayhem-performance-group dd small` 规则删除。
