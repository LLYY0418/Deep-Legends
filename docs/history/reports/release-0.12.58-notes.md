# v0.12.58

包含 0.12.19 之后的累计更新，本次重点：

- 快速模式、匹配、大乱斗、冠军杯和无限火力补齐缺席的隐藏玩家；电脑玩家不计入匿名人数。
- 隐藏身份卡片保留英雄与位置，移除无依据的段位、重复提示和无数据的战绩列。
- 战绩名单突出当前玩家；构建页增加本局符文效果、分类汇总和海克斯效果卡片。
- 修复斗魂高手对局补全后名单和伤害未刷新、加载失败后无法重试的问题。
- 改善实时名单、当前模式最新战绩、赛后排位缓存与 LP 记录；减少重复刷新和页面重建。
- 便携版和旧版支持软件内下载、校验及重启升级；升级延续本地数据，安装失败保留当前程序。
- 增加“保留对局内设置改动”，补齐收藏目录、对位提示和排障诊断。

完整改动见 [CHANGELOG](https://github.com/LLYY0418/Deep-Legends/blob/33e4e4a882a3bac7fba99b40325a625bda65f13a/CHANGELOG.md)。

下载 `Deep-Legends-Setup-0.12.58-public.exe` 安装。公开包不包含个人 Riot API Key。仍使用 0.12.19 的用户请从本页手动下载安装，新版本已修复公开包文件名的更新校验兼容问题。
