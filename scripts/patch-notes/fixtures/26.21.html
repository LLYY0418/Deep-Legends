    26.21版本更新公告

    2026-10-21 20:27:31 字体：
    大 中 小
    次阅读

    LOL将在10月22日凌晨0点开始全区停机维护(请注意：10月21日23点将关闭排位赛入口，不会影响正在进行中的排位赛)发布26.21版本，预计停机时间为0:00-12:00 。对于在停机期间结束的活动，其实际结束时间也将提前至停机维护开始时，敬请留意

      全球总决赛已经开启，但对于非职业玩家来说，峡谷中的时间仍然照常流逝——欢迎来到26.21版本。这是一次内容相当丰富的版本更新，调整了拉莫斯、赛恩、努努和威朗普等英雄，同时也平衡了在各自位置上表现突出或过于强势的其他英雄。随着全球总决赛版本目标锁定，其他英雄会有更多调整空间，比如阿兹尔、奥莉安娜和瑞兹。最后，我们发现【贪欲之靴】和【狂妄】在远程英雄手中表现过于强势，因此它们会被小幅削弱，【黎明核心】在得到增强后，也许能出现在更多的出装中。

    走错版本公告了？点击此处前往【云顶之弈】版本公告！

     注：国服的公告基于国服更新的实际版本数值，Riot游戏设计团队如在版本内对平衡性进行调整，国服运营团队将根据更新筹备进度发布版本内更新公告。后续可能基于实际运行效果进行优化，且不同机器配置下效果可能不同。

    账号系统后台升级

    本次版本发布期间将同步进行账号系统后台升级。系统升级完成后，官网各项运营活动、转区系统、解冻系统和账号注销系统将陆续恢复开放。

    英雄

    沙漠皇帝 阿兹尔

      团队之前刻意限制了这位沙漠皇帝的法力值储备，以确保他在对线初期必须合理利用沙兵的攻击来控线，而非仅仅无脑频繁施放【Q狂沙猛攻】。然而，鉴于现在升级【W沙兵现身】能带来显著的收益，这种法力限制显得过于严苛了。团队加强了他的成长法力值，好让他能更加自如地使用他的技能来争抢线权。

          基础属性
          成长法力值：40/等级 ⇒ 50/等级

    皮城女警 凯特琳

      凯特琳在过去数月里对大多数玩家而言始终保持着极高的禁用率和选用率，尽管团队针对其他射手英雄以及下路生态环境进行过调整。因此，是时候削弱她了。团队早就觉得她的后期成长能力过于强劲了。因此，团队将她的一部分强度从她“惊爆眼球的满装爆头”中转移到了“游戏前期的Q技能伤害”上，从而重新平衡她的强度曲线。

    被动 - 爆头
          伤害：60 - 100%攻击力(每1%暴击几率+1%攻击力) (每1%额外暴击伤害+1%攻击力) ⇒ 60 - 80%攻击力(每1%暴击几率+1%攻击力) (每1%额外暴击伤害+1%攻击力)

    Q - 和平使者
          基础伤害：50 / 90 / 130 / 170 / 210 ⇒ 50 / 95 / 140 / 185 / 230

    诺克萨斯之手 德莱厄斯

      德莱厄斯现在更偏向于一套爆发秒人的玩法，过于偏离了“需要被风筝、又肉又有输出的危险人物”这一风格。由于他还有成长空间，团队稍微增强了他，让他在持久战中能更频繁地挥动战斧。

    Q - 大杀四方
          冷却时间：9 / 8 / 7 / 6 / 5秒 ⇒ 9 / 8 / 7 / 6 / 4秒

    暴走萝莉 金克丝

      和她的闺蜜凯特琳一样，金克丝在当前版本依然非常强势，即使在上个版本【飓风】被削弱之后。团队正在削弱她的节奏，让她更难滚起雪球。

          基础属性
          攻击力：59 + 3.25/等级 ⇒ 59 + 3/等级
          生命值：630 + 105/等级 ⇒ 610 + 105/等级

    盲僧 李青

      自从李青的【W金钟罩】与友军互动时的冷却时间得到调整后，他一直非常受欢迎。虽然团队喜欢这为他带来的额外灵活性，但这也让他有点过于强势，所以团队会稍微削弱他的冷却时间，并修复一个关于他的E技能在显形隐身敌人时的小问题，同时还会小幅削弱他的【R猛龙摆尾】伤害。

    W - 金钟罩
          冷却时间：7秒 ⇒ 8秒

    E - 天雷破
          BUG修复：如果敌人在被【天雷破】命中后进入隐身，将不再被显形。

    R - 猛龙摆尾
          踢击伤害：175 / 400 / 625 (+200%额外攻击力) ⇒ 150 / 350 / 550 (+200%额外攻击力)
          碰撞伤害：175 / 400 / 625 (+200%额外攻击力) (+12 / 15 / 18%被踢英雄的生命值) ⇒ 150 / 350 / 550 (+200%额外攻击力) (+12 / 15 / 18%被踢英雄的生命值)

    灰烬驱魔人 洛克

      洛克上线已经有一段时间了，团队现在能更清楚地看到他在哪些方面表现过于出色，哪些方面还有些不足。前者包括他极为强大的法力调整和抗骚扰能力，并且团队还略微提升了他的技能伤害成长来略微改善他的强度曲线，因为如果他无法在前期结束比赛，他的表现就会迅速下滑。

          基础属性
          成长法力值：70 ⇒ 60

    Q - 伏魔三钉
          未使用充能返还：20 - 35%法力值和冷却时间返还 ⇒ 10 - 40%法力值和冷却时间返还

    W - 灵焰仪式
          法力消耗：50 / 55 / 60 / 65 / 70 ⇒ 60 / 65 / 70 / 75 / 80
          根据当前生命值的灰色生命值储存：40-200 (基于等级的部分) ⇒ 20-200 (基于等级的部分)
          当前生命值储存：150 - 450 (基于等级的部分) ⇒ 100 - 500 (基于等级的部分)

    E - 灰猎无影
          闪烁伤害：40 / 50 / 60 / 70 / 80 (+40%法术强度) ⇒ 40 / 55 / 70 / 85 / 100 (+50%法术强度)

    赏金猎人 厄运小姐

      厄运小姐在今年整体表现还算不错，但随着这个版本对【狂妄】的削弱，团队打算通过提升她的伤害来进行一些补偿。

    E -枪林弹雨
          伤害：70 / 100 / 130 / 160 / 190 (+120%法术强度) ⇒ 90 / 120 / 150 / 180 / 210 (+120%法术强度)

    R - 弹幕时间
          暴击伤害：130% (每1%额外暴击伤害+0.3%) ⇒ 145% (每1%额外暴击伤害+0.45%)

    狂野女猎手 奈德丽

      这位广受喜爱的女猎手在高水平段位的胜率一直居高不下，已经接近过强的边缘，哪怕她现在并不算主流选择。由于团队正在削弱其他一些强势的主流打野英雄，比如盲僧，因此也对奈德丽进行了一些小幅削弱，以防她变得过于强势。

    W - 猛扑
          伤害：  伤害：55 / 100 / 145 / 190 (+50%额外攻击力) (+30%法术强度) ⇒ 50 / 90 / 130 / 170 (+50%额外攻击力) (+30%法术强度)

    E - 野性奔腾
          攻击速度：30 / 40 / 50 / 60 / 70% ⇒ 20 / 30 / 40 / 50 / 60%

    雪原双子 努努和威朗普

      今年早些时候，团队不希望远程法师只是为了位移而购买【海克斯科技火箭腰带】，因此削弱了它。于是某个小男孩和他的雪人失去了一些强度，所以团队现在会在其他地方补回一部分伤害。

    R - 绝对零度
          最大伤害：625 / 925 / 1275 (+300%法术强度) ⇒ 750 / 1100 / 1450 (+300%法术强度)

    发条魔灵 奥莉安娜

      团队提升了奥莉安娜的技能成长性，让她在后期用招牌连招打出更高爆发的同时，不会让她在对线期变得过强。

    Q - 指令：攻击
          伤害：60 / 90 / 120 / 150 / 180 (+55%法术强度) ⇒ 60 / 90 / 120 / 150 / 180 (+60%法术强度)

    W - 指令：杂音
          伤害：70 / 110 / 150 / 190 / 230 (+80%法术强度) ⇒ 70 / 110 / 150 / 190 / 230 (+85%法术强度)

    元素女皇 奇亚娜

      奇亚娜的Q技能造成的伤害比团队预期的要高得多，因此团队将部分回调她在26.17版本获得的加强。

    Q - 元素之怒 / 以绪塔尔之锋
          伤害：80 / 110 / 140 / 170 / 200 (+90%额外攻击力) ⇒ 70 / 100 / 130 / 160 / 190 (+90%额外攻击力)

    披甲龙龟 拉莫斯

      虽然奈德丽在高水平局的胜率已经快要超出“过于强势”这条线了，但拉莫斯几乎碾过了其他所有人，所以他也会得到小幅削弱。

    W - 尖刺防御
          额外护甲：27 / 32 / 37 / 42 / 47 (+30 - 60%护甲) ⇒ 25 / 30 / 35 / 40 / 45 (+30 - 50%护甲)
          额外魔法抗性：20 / 25 / 30 / 35 / 40 (+30 - 60%魔法抗性) ⇒ 20 / 25 / 30 / 35 / 40 (+30 - 50%魔法抗性)

    符文法师 瑞兹

      在26.19版本对瑞兹前期的大幅削弱后，即使他发挥出色，也无法获得足够的回报，所以团队将提升他的后期表现。

    Q - 超负荷
          涌动 额外伤害：15% / 40% / 65% / 90%额外伤害 ⇒ 10% / 40% / 70% / 100%额外伤害
          额外移动速度：28% / 32% / 36% / 40% / 44% ⇒ 30% / 35% / 40% / 45% / 50%

    W - 符文禁锢
          伤害：60 / 90 / 120 / 150 / 180 (+60%法术强度) (+3%额外法力值) ⇒ 60 / 90 / 120 / 150 / 180 (+70%法术强度) (+3%额外法力值)

    亡灵战神 赛恩

      这位广受喜爱的重装战士在最近的版本中好像没那么不可阻挡了。团队会提升他的基础耐久力，并且奖励他用大招成功“落位”而不是逃跑。

          基础属性
          生命值：655 + 87/等级 ⇒ 655 + 95/等级

    R - 蛮横冲撞
          引导最初3秒内的伤害提升：+0 - 166.67%基础伤害，0 - 100%收益伤害 ⇒ +0 - 200%
          BUG修复：现在的说明文本会正确显示最小和最大额外攻击力收益率(40-120%)。之前显示了错误的额外攻击力收益率(60%-120%)。实际上在25.16版本并没有改动它。

    岩雀 塔莉垭

      塔莉垭是为数不多的法师打野之一，团队认为她可以得到更多支持，以丰富版本格局的多样性。团队会提升她的【E撒石阵】伤害，让她的控制连招命中时更加爽快。

    E - 撒石阵
          伤害：60 / 105 / 150 / 195 / 240 (+60%法术强度) ⇒ 70 / 115 / 160 / 205 / 250 (+70%法术强度)
          引爆伤害：25 / 40 / 55 / 70 / 85 (+30%法术强度) ⇒ 30 / 45 / 60 / 75 / 90 (+30%法术强度)
          野怪伤害：对野怪造成225%伤害。

    瓦洛兰之盾 塔里克

      团队正在打磨塔里克的技能组，让他能够更加闪耀。很久以前，为了对抗当时流行的易加塔里克的让经济战术，团队调整了塔里克的W技能。造成的一个结果是，如果他绑定的友军在他施放技能的同时变为不可被选取，他的技能就会失效。鉴于现在有了分路任务，团队认为对他技能机制的这一严苛限制已无必要，因此会部分回调这一改动，现在技能可以作用于不可被选取的友军，但【E炫光】仍然会不适用那些在屏幕上消失的英雄，因为这会导致相关玩法过于不清晰（抱歉了，易）。

    Q - 星光之触
          施放判定：现在，即使友军处于不可被选取状态时，Q技能也能成功施放。

    E - 炫光
          施放判定：在友军处于不可被选取状态时施放E技能，现在可以成功发射炫光。
          说明文本：已更新以包含“消失的友军无法发射炫光”。

    R - 宇宙之辉
          施放判定：现在，当友军处于不可被选取时，R技能施放将能成功施放。

    麦林炮手 崔丝塔娜

      崔丝塔娜的前期线上现在有点变成了“1级按[Q] ，然后疯狂普攻，直接掌控整条线”，这种玩法既无趣又不符合她的特色。团队削弱了她前期的[Q]攻击速度，这样她必须多下点功夫才敢扑向敌人。

    Q - 急速射击
          攻击速度：60 / 75 / 90 / 105 / 120% ⇒ 40 / 60 / 80 / 100 / 120%

    卡牌大师 崔斯特

      除了塔里克的体验优化外，团队也为崔斯特的R技能带来了同样的调整，现在即使敌方英雄在施放技能时处于无法被选中的状态，也能被显形。

    R - 命运
          显形：现在可以显形不可被选取的单位。

    惩戒之箭 韦鲁斯

      在这轮改动中，团队主要针对上路韦鲁斯出手，因为他在上路通常主W，而不像下路更常见的主Q。这不会让他的【Q穿刺之箭】恢复到之前穿甲韦鲁斯的强度，但会大幅增加下路韦鲁斯技能的调整空间。作为满级技能，它为韦鲁斯和他的对手提供了更多互动玩法，而不仅仅是W技能上的被动伤害。

    Q - 穿刺之箭
          伤害计算：最大伤害增长，53.33 - 240(+80%额外攻击力)至80 - 360(+120%额外攻击力) ⇒ 最小伤害增长，50 - 230(+80%额外攻击力)至85 - 391(+136%额外攻击力)
          随引导时间提升伤害：提升幅度上限为50% ⇒ 提升幅度上限为70%

    W - 枯萎箭袋
          附带伤害：4 / 13 / 22 / 31 / 40 (+15%额外攻击力) (+25%法术强度) ⇒ 4 / 10 / 16 / 22 / 28 (+20%额外攻击力) (+30%法术强度)
          每层伤害：3 - 5% (每100法术强度提升1.3%)目标最大生命值 ⇒ 2.5 - 4.5% (每100法术强度提升1.4%)目标最大生命值
          主动 已损失生命值伤害：6-14%，可通过Q引导来提升，提升幅度上限为50% (9-21%) ⇒ 6-10%，可通过Q引导来提升，提升幅度上限为70% (10.2-17%)
          基础技能 冷却时间返还：每层13%，可通过Q引导来提升，提升幅度上限为50% (每层19.5%) ⇒ 11%，可通过Q引导来提升，提升幅度上限为70% (每层18.7%)

    虚空之眼 维克兹

      维克兹今年一直是个相当冷门的选择，在中路和辅助位置几乎没有存在感，也无法对玩法产生影响。团队希望给他一点小小的帮助，方法是让他在打出连招时获得更多回报。

    被动 - 有机体解构
          伤害：35 - 180 (+60%法术强度) ⇒ 35 - 205 (+65%法术强度)

    Q - 等离子裂变
          冷却时间：7秒 ⇒ 6秒

    机械先驱 维克托

      是时候迎接光荣进化了。看起来维克托已经进化到几乎没有可被利用的弱点了，因此团队将稍微加深他在前期遭遇战和各个方面的脆弱性。

          基础属性
          移动速度：335 ⇒ 330

    Q - 虹吸能量
          护盾值：40 - 140 (基于等级) (+25%法术强度) ⇒ 30 - 130 (+20%法术强度)
          护盾持续时间：2.5秒 ⇒ 2秒

    齐天大圣 孙悟空

      和李青、奇亚娜一样，孙悟空在打野位上也已经成为了版本热门，能只手翻云覆雨的强力存在。团队希望削弱他在打野位的强度，同时补偿他的打线位。

          基础属性
          生命回复：3.5 + 0.65/等级 ⇒ 5.5 + 0.65/等级

    被动 - 金刚不坏
          每层护甲：6 - 10 (基于英雄等级) ⇒ 4.5 - 10 (基于英雄等级)

    德邦总管 赵信

      在【焚天】削弱后，团队认为赵信的物理半肉和攻速流出装都有提升空间，因此团队将加强他的成长性。

    Q - 三重爪击
