    26.17版本更新公告

    2026-08-26 20:36:55 字体：
    大 中 小
    次阅读

    LOL将在8月27日凌晨0点开始全区停机维护(请注意：8月26日23点将关闭排位赛入口，不会影响正在进行中的排位赛)发布26.17版本，预计停机时间为00:00-12:00 。对于在停机期间结束的活动，其实际结束时间也将提前至停机维护开始时，敬请留意

      在26.17版本中，团队稍微缓和了上路的局势，削弱了内瑟斯和薇恩，并对上一版本中的部分英雄和装备进行了后续调整。团队还会加强一批近战伤害型英雄，如艾瑞莉娅、奇亚娜、亚索、永恩，这段时间他们如果滚不起来雪球就必输，没有可靠的后期成长空间。泽拉斯在中路的表现依然过于强势，魔腾和格雷福斯在打野位置也是一样。最后，【焚天】的削弱力度没有达到预期，团队还希望【岚切】能重新在部分出装中占有一席之地。

    走错版本公告了？点击此处前往【云顶之弈】版本公告！

     注：国服的公告基于国服更新的实际版本数值，Riot游戏设计团队如在版本内对平衡性进行调整，国服运营团队将根据更新筹备进度发布版本内更新公告。后续可能基于实际运行效果进行优化，且不同机器配置下效果可能不同。

    版本要闻

     

    【心之歌 萨勒芬妮】、【海之歌 索拉卡】和【海之歌 金克丝】已在26.17版本内。

    英雄

    铸星龙王 奥瑞利安·索尔

      奥瑞利安·索尔在上个版本的法师调整中成了输家，所以团队会为他带来一次增强，以助他一臂之力。特别是，团队加强了他的W技能冷却时间，让他可以更自由地使用W，而不是只在有可能重置时才用。这也能让玩家更清楚地知道，W而不是E更适合作为副升技能。

    Q - 星河冲荡
           每秒法力消耗：35 / 40 / 45 / 50 / 55 ⇒ 30 / 35 / 40 / 45 / 50

    W - 星穹流丽
           冷却时间：22 / 20.5 / 19 / 17.5 / 16秒 ⇒ 22 / 20 / 18 / 16 / 14秒

    虚空恐惧 科加斯

      由于【丛刃】和【海克斯科技火箭腰带】被削弱，科加斯的前期表现失去了亮点，因此团队会通过提升他前期普攻命中时的伤害来进行补偿。

    E -恐惧之刺
           基础伤害（3次攻击）：20 / 40 / 60 / 80 / 100（+30%法术强度）（+2.5% - 3.9%（每层盛宴+0.5%）目标最大生命值）⇒30 / 50 / 70 / 90 / 110（+30%法术强度）（+2.5% - 3.9%（每层盛宴+0.5%）目标最大生命值）

    法外狂徒 格雷福斯

      格雷福斯在最近几个版本中获得了不少间接增强，这让他现在的表现非常强势。团队希望稍微削弱他“通过高攻击力出装来滚雪球”的能力。

    Q - 穷途末路
           第一段伤害：50 / 75 / 100 / 125 / 150 (+65% 额外攻击力）⇒ 50 / 75 / 100 / 125 / 150 (+55%额外攻击力)
           返程伤害：80 / 125 / 170 / 215 / 260 (+55 / 70 / 85 / 100 / 115%额外攻击力) ⇒ 80 / 125 / 170 / 215 / 260 (+45 / 60 / 75 / 90 / 105%额外攻击力)

    刀锋舞者 艾瑞莉娅

      艾瑞莉娅是《英雄联盟》中最依赖滚雪球的高风险游击战士之一，但感觉即使她取得领先，也很难成长为真正的核心威胁。

    Q - 利刃冲击
           伤害：5 / 25 / 45 / 65 / 85 (+70%攻击力) ⇒ 5 / 25 / 45 / 65 / 85 (+80%攻击力)
           此外团队还提升了她的法术强度收益率，鼓励玩家在大乱斗和竞技场中尝试有趣的出装。但这应该不会让法强艾瑞莉娅在召唤师峡谷突然变强。

    W - 距破之舞
           伤害减免 法术强度收益率：每100法术强度提升7%（对魔法伤害减半）（在竞技场中对魔法伤害降至75%效能） ⇒ 每100法术强度提升8%（对魔法伤害减半）（在竞技场中对魔法伤害降至75%效能）

    R - 先锋之刃
           法术强度收益率：70% ⇒ 100%（在斗魂竞技场中已经是100%，这次是统一数值）

    诡术妖姬 乐芙兰

      随着之前导致她攻击速度加成被削弱的【斯塔缇克电刃】已经更新换代，团队会让她的属性更接近普通英雄的基础水平。与此同时，考虑到她还有一定的强度空间，团队将提升她的一些法强收益率，确保她依然更倾向于法强刺杀流出装。

           基础属性
           攻击速度收益率：0.4 ⇒ 0.625
           成长攻击速度：2.35% ⇒ 1.5%

    W - 魔影迷踪
           伤害：75 / 115 / 155 / 195 / 235 (+80%法术强度) ⇒ 75 / 115 / 155 / 195 / 235 (+90%法术强度)
           RW - 故技重施：魔影迷踪
           伤害：150 / 315 / 480 (+80%法术强度) ⇒ 150 / 315 / 480 (+90%法术强度)

    沙漠死神 内瑟斯

      上单内瑟斯一直能够从他的叠层范式的迁移中获益。团队很高兴看到人人都爱的大狗吃得饱饱的，但也希望确保他的强度保持在合理范围内，因此团队将削弱内瑟斯在上路的一些特定强势点，比如持续从小兵身上吸取生命值。

    被动 - 吞噬灵魂
           生命偷取：12 / 18 / 24% ⇒ 10 / 15 / 20%

    永恒梦魇 魔腾

      魔腾在各个技术水平的玩家中处于相当强势的状态已经有一阵子了。团队很期待魔腾开启大招时带来的各种可能，但也希望在他发挥这种高光时刻时多承担一些个人风险。

           基础属性
           护甲：38 ⇒ 36
           生命值：655 ⇒ 640

    元素女皇 奇亚娜

      奇亚娜的出场位置已经从主要的中路转向了打野。虽然团队很乐意支持她担任打野位，但她最近在中路的表现一直不尽如人意。

    Q - 元素之怒
           伤害：70 / 100 / 130 / 160 / 190 (+85%额外攻击力）⇒ 80 / 110 / 140 / 170 / 200 (+90%额外攻击力)
           野怪伤害修正率：对野怪造成175%伤害 ⇒ 对野怪造成160%伤害

    魂锁典狱长 锤石

      锤石的胜率一直居高不下，且这一年来登场率也在不断提升。

    E - 厄运钟摆
           主动伤害：75 / 120 / 165 / 210 / 255 (+70%法术强度) ⇒ 65 / 110 / 155 / 200 / 245 (+60%法术强度)

    巨魔之王 特朗德尔

      有时候你只想挥舞大棒把对手全都敲翻！虽然凭借冰柱和大招特朗德尔一直是个坚韧的功能型选择，但团队觉得他耍大棒的能力其实还有提升空间。

    W - 冰封领域
           攻击速度：30 / 45 / 60 / 75 / 90% ⇒ 30 / 50 / 70 / 90 / 110%

    暗夜猎手 薇恩

      团队认为薇恩未来可能需要更大范围的调整来帮助她的下路表现，但目前团队优先限制她在上路的强度。这些改动在上路对她的影响应该会大于在下路。

           基础属性
           生命值：550 + 103/等级 ⇒ 580 + 98/等级
           生命回复：3.5 + 0.55/等级 ⇒ 4 + 0.5/等级
           攻击速度收益率：0.658 + 3.3%/等级 ⇒ 0.67 + 2.8%/等级

    Q - 闪避突袭
           法力消耗：30 ⇒ 46 / 42 / 38 / 34 / 30

    W - 圣银弩箭
           真实伤害：6 / 7 / 8 / 9 / 10%目标最大生命值 ⇒ 4 / 5.5 / 7 / 8.5 / 10%目标最大生命值
           最小伤害：50 / 65 / 80 / 95 / 110 ⇒ 40 / 55 / 70 / 85 / 100

    远古巫灵 泽拉斯

      泽拉斯在中路和下路的强度一直略高，上一版本对法师的调整后，他在中路线上表现尤为突出，超越了其他英雄。鉴于他在某些地区的禁用率极高，团队准备对他进行小幅削弱。

           基础属性
           生命值：596 ⇒ 575

    Q - 奥能脉冲
           伤害：75 / 115 / 155 / 195 / 235 (+90%法术强度) ⇒ 70 / 110 / 150 / 190 / 230 (+90%法术强度)

    疾风剑豪 亚索

      虽然亚索确实能够滚起雪球并带领队伍取胜，但团队认为他和艾瑞莉娅一样，过于依赖雪球效应，而不算真正的成长型核心。团队也希望鼓励他优先选择前期暴击装备而不是【破败王者之刃】，因此团队下调了他的暴击伤害惩罚，不仅能推动他走这种路线，还能帮助他更好地成长，同时不会对他的前期滚雪球能力造成太大影响。

    被动 - 浪客之道
           暴击伤害减免：-10% ⇒ -5%

    封魔剑魂 永恩

      和亚索类似，永恩同样也是一个过于依赖滚雪球来发挥的核心，不过程度稍轻一些。兄弟就是要在一起。

    被动 - 狩人之道
           暴击伤害减免：-10% ⇒ -5%（相当于基础暴击伤害从180%提升至190%）

    装备

    岚切

      【岚切】今年年初差点迎来自己的高光时刻，但最终还是沦为配角。

           攻击速度：20% ⇒ 25%

    焚天

      上个版本对【焚天】的削弱是正确的一步，但考虑到该版本的其他调整，削弱力度还是略显不足。

           生命值：450 ⇒ 400
           攻击力：45 ⇒ 40

    经典模式

       《英雄联盟》经典模式的第二批更新，来看看都有哪些精彩内容！团队将为所有玩家额外赠送两个符文页，全面提升金币和经典模式经验获取速度，并下调约三分之一符文的价格。更新了召唤师峡谷的光照、材质和贴花，让画面效果更贴近早期的峡谷风格。首次理事会投票也即将展开，记得登录游戏，发表你的看法。记住，参与更多经典模式，能获得更多投票权！

    此外，团队还带来了约20项平衡性调整、数十项BUG修复，并在选英雄阶段新增了英雄与分路交换功能，让你的经典模式体验更加顺畅。

    英雄

    阿狸

       阿狸是个非常安全的选择，具备出色的续航能力、清线能力，还能随时抓住机会对对手发起全力进攻。也就是说，她太强了。团队希望削弱她前期过剩的能力保障，并减少她对对手施加压力的频率。

    基础属性

    • 基础生命回复：6.1 ⇒ 4.5
    • 成长生命回复：0.6 ⇒ 0.45
    • 生命值：460 ⇒ 440

    R - 灵魄突袭

    • 冷却时间：110 / 95 / 80 ⇒ 120 / 100 / 80

    安妮

      安妮是中路第二弱的英雄，只比拉克丝强点，所以团队准备对她进行一些增强。团队首先会撤销她在2011年7月受到的伤害削弱，同时确保她的进攻威胁依然足够强大。

    被动 - 嗜火

    • 晕眩时长：1.5秒 ⇒ 1.75秒

    Q - 碎裂之火

    • 伤害：85 / 125 / 165 / 205 / 245 + 70%法术强度 ⇒ 90 / 130 / 170 / 210 / 250 + 75%法术强度

    W - 焚烧

    • 伤害：80 / 130 / 180 / 230 / 280 + 75%法术强度 ⇒ 85 / 135 / 185 / 235 / 285 + 80%法术强度

    E -熔岩护盾

    • BUG修复：修复了一个BUG，该BUG曾导致：【熔岩护盾】造成的伤害过低。
    • BUG修复：修复了一个BUG，该BUG曾导致：【熔岩护盾】在受到非普攻的伤害时也会回敬伤害。

    R - 提伯斯之怒

    • BUG修复：修复了一个BUG，该BUG曾导致：法术强度未施加至提伯斯的灼烧伤害。

    艾希

      作为一名辅助型ADC，艾希的表现低于平均水平。她并不是特别弱，但也值得获得一次增强。为此，团队会回调2010年对万箭齐发的削弱，让她在远距离作战时能够更好地发挥优势，从远处消耗并压制对手。

    W - 万箭齐发

    • 伤害：40 / 50 / 60 / 70 / 80 + 100%总攻击力 ⇒ 40 / 55 / 70 / 85 / 100 + 100%总攻击力
    • 距离：1200 ⇒ 1300

    布里茨

      布里茨应该受到比上个版本更大幅度的削弱，因此团队回来让这位游戏中最具影响力的辅助回归正常水平。团队会继续回顾旧版本，撤回之前效果较弱的数值调整。还会修复一些BUG和疏漏，进一步削弱他的强度。一个独特的调整是削弱了静电力场主动技能在1级和2级时的效果。配合冷却时间的削弱，团队希望布里茨玩家有时也会选择让R技能保持被动形态，以便打出更持久的伤害威胁。

    被动 - 法力屏障

    • 说明文本：明确说明只有当布里茨在受到伤害时生命值低于20%时，法力屏障才会触发。
    • 护盾值：50%最大法力值 ⇒ 50%当前法力值

    Q - 机械飞爪

    • 距离：1080 ⇒ 1050
    • 法力消耗：120 ⇒ 140

    E - 能量铁拳

    • BUG修复：修复了一个BUG，该BUG曾导致：无论技能等级或冷却缩减如何，冷却时间始终为5秒。
    • BUG修复：修复了一个BUG，该BUG曾导致：目标被晕眩时间比预期多约0.3秒。

    R - 静电力场

    • 主动伤害：200 / 300 / 400 ⇒ 150 / 275 / 400
    • 冷却时间：30秒 ⇒ 40秒

    蒙多医生

      虽然在上个版本得到了加强，但蒙多医生还是游戏中最弱的上路和打野之一，急需更多的医疗介入。团队这不就来了，这次进一步提升了他的耐久力，希望让他成为你见过最厚的肉盾。他增加的生命值来自对2011年4月削弱的撤回。团队还为他来了点额外的前期攻击速度，主要是为了大幅提升他的打野能力，因为他目前在打野位的表现不如上路。

    基础属性

    • 生命值：522 ⇒ 560
    • 成长生命值：89 ⇒ 90
    • 1级时的攻击速度：0.625 ⇒ 0.658（注：暂未生效，将于后续版本修复）

    伊芙琳

      伊芙琳是经典模式中表现最出色的打野英雄之一，随着玩家不断学习如何优化她的玩法，她的胜率也在持续提升。因此，这次她会受到削弱。团队会结合她最初上线时被撤销的增强调整，以及2013年后续的削弱调整。团队削弱了她频繁使用黑暗狂暴时的地图穿梭能力，降低了中后期的打野清野速度，让她像其他法强打野一样需要更加注意法力消耗。

    被动 - 暗影迷踪

    • 伪装状态下的最大法力回复：1% ⇒ 0.8%

    Q - 憎恨之刺

    • 基础伤害：40 / 60 / 80 / 100 / 120 ⇒ 40 / 55 / 70 / 85 / 100
    • 弹体速度：3000 - 800，持续衰减 ⇒ 2000 - 800，持续衰减

    W - 黑暗狂暴

    • 法力消耗：0 ⇒ 40
    • 冷却时间：15秒 ⇒ 20秒

    伊泽瑞尔

      随着玩家们逐渐找回手感，伊泽瑞尔已经稳居下路首选，成为最受欢迎的下路英雄，并且凭借极高的安全性，在表现上过于强势。由于当前物理伊泽瑞尔是主导，团队会进行一些补偿性调整，以确保法强伊泽瑞尔同样能够保持竞争力。本次削弱可以说是2010年6月的改动巡礼，带来了两个Q技能的削弱，并撤销了16年前对R技能的削弱。

    Q - 秘术射击

    • 总攻击力收益：120% ⇒ 110%
    • 施放距离：1200 ⇒ 1100

    R - 精准弹幕

    • 法术强度收益率：70% ⇒ 100%

    盖伦

      上个版本团队的许多改动都比较保守，这让盖伦依然处于非常弱势的状态。团队这次会带来更强力的加强，目标是让他赶上当前的节奏。这些加强有两个主要目标。首先要确保旋转至胜在游戏前期始终能带来成就感。另一个目标是确保他在购买所有装备时都能有良好的体验，无论是提升伤害还是增强生存能力。

    基础属性

    • 攻击力：55.5 ⇒ 60
    • 成长护甲：2.7 ⇒ 3

    斗魂竞技场

       随着斗魂竞技场在玩家和玩法平衡方面逐渐稳定，团队希望继续调整那些表现异常的英雄，特别是加强那些在该模式中难以立足的英雄，同时削弱过于强势、阻碍其他英雄在这个模式立足的角色。

    未来，斗魂竞技场也将恢复为交替更新的节奏，预计在奇数版本上线时推出平衡性更新。团队认为该模式的状态较为健康，并且也不希望频繁调整，让玩家觉得自己的出装和发明很快就会被削弱。
