# Deep Legends

一款 Windows 本地英雄联盟助手，核心是两件事：

- **总览**：一个页面看清任何一名玩家的段位、整赛季英雄数据、能力表现和带评分的完整战绩。
- **对局**：从选人开始看清双方每一个人，锁定英雄后给出符文、出装和海克斯推荐，一键写入客户端。

另外还有不用登录也能查的英雄梯度、皮肤收藏与三合一奖池核对，以及一组自动化工具。

- 不需要输入账号密码，也不接管登录，只读取本机已登录的客户端。
- 客户端凭据和收藏数据不离开本机。
- 支持腾讯国服，以及韩服、日服、欧美、东南亚等 Riot 区服。

> 本项目不是腾讯、Riot Games 或英雄联盟官方产品。

## 核心功能

### 总览：一个页面看清一名玩家

客户端登录后，总览自动打开你自己的页面；也可以在顶部搜索任意国服子服务器或外服玩家，每个玩家一个标签页。国服和外服分组显示，服务器名标在名字旁边。

**生涯面板**

- **排位**：单双排、灵活组排的段位、胜点和胜率；海克斯大乱斗额外显示隐藏分估算。
- **英雄胜率**与**英雄数据表**：回补整个赛季的对局，按单双排、灵活组排、海克斯大乱斗分别统计每个英雄的场次、胜率和 KDA，可以整行展开看对位表现。
- **位置偏好**、**英雄熟练度**（含完整熟练度页）、**游戏时间分布**。
- **能力表现**：七维能力雷达，拿本人和近期同位置对手的数据做比较，看出强项和短板。
- **最近一起玩**：最近经常同场的玩家，点一下就能打开他的总览。
- **正在进行的游戏**：被查询的玩家正在对局时，直接显示这一局的阵容。

**战绩**

- 每张战绩卡都有模式、胜负、时长、英雄、召唤师技能、符文、K/D/A 和完整出装，并标注：
  - **单场评分**与本场排名、MVP / SVP，悬停可以看各项分数是怎么构成的；
  - **数据标签**：伤害、承伤、单杀×N、参团、补刀等本场的突出表现，放不下时显示 +N；
  - 多杀、零阵亡、连胜连败；
  - 排位对局的**胜点增减**，以及这一场的**平均段位**。
- 按单双排、灵活组排、海克斯大乱斗、斗魂竞技场等模式筛选，滚动到底部自动加载更多。
- 展开一场对局可以看到：
  - **概览**：双方十人的完整数据；
  - **队伍分析**：击杀、金币、伤害、视野等指标的红蓝对比；
  - **构建**：可以切换到任意一名玩家，看他的出装顺序（按分钟）、技能加点、符文和海克斯；
  - 支持下载并观看客户端回放。
- 斗魂竞技场按小队和名次展示全部选手。

### 对局：从选人到游戏结束全程陪伴

进入选人阶段后，对局页马上读出双方阵容，不用一个个手动搜索。

**看清双方每一个人**

- 双方玩家的段位、当前模式近期战绩（从新到旧排开的胜负条）、胜率、KDA、常用位置和连胜连败。
- 自动识别**组队开黑**的玩家，标出职业选手的账号。
- 选人阶段自动刷新，进入游戏后数据齐全就停止刷新；随时可以手动刷新。
- 点开任意一名玩家，直接看他的完整战绩和单场详情。
- 斗魂竞技场自动按小队分组，自己的小队排在前面；中途重启应用也能恢复。
- 阵容克制与协同提示。

**锁定英雄后的推荐**

- 符文、召唤师技能、技能加点、出门装、核心装备、鞋子；斗魂竞技场还有棱彩装备，海克斯模式还有海克斯推荐。
- 推荐来源可以切换：**OP.GG 韩服统计**、**绝活哥**（韩服高分玩家这个英雄的实际符文）、**职业选手**（职业比赛中的符文），以及客户端内置推荐。
- 一键写入客户端：符文只会新建页面，不覆盖你已有的符文页；装备方案只更新 Deep Legends 自己创建的那一套。

## 更多功能

### 英雄数据

- 不用登录客户端，就能查看韩服各位置、各段位的英雄梯度、符文、出装和克制关系。
- 海克斯大乱斗有单独的英雄梯度和完整海克斯图鉴。
- 英雄搜索支持中文、英文、拼音、首字母和常见外号。

<!-- 截图：英雄梯度与详情 -->
<!-- ![英雄](screenshots/champions.png) -->

### 收藏

- 已拥有和全部皮肤、炫彩、臻彩、头像、旗帜分开浏览，按英雄、品质、获取时间排序，可以全屏看原画。
- 三合一奖池：用稳定皮肤 ID 核对当前账号，准确列出奖池里还没有的皮肤。
- 战利品、精粹、钥匙一览，支持导出 JSON、CSV 和离线 HTML。

<!-- 截图：皮肤收藏 -->

### 工具

- **自动**：自动接受对局、再来一局、断线重连、结算点赞等，每一项默认关闭，需要你自己逐项开启。
- **征召**：按模式和位置预设禁用、选用英雄，自动亮出和锁定。
- **生涯**：设置生涯背景皮肤、聊天状态和展示段位。
- **领奖**：扫描待领取的奖励、任务和活动，逐项领取。
- **好友**：只读好友面板，能看到好友在线状态和正在玩的英雄，点一下就能查他的战绩。

### 职业选手

收录 BLG、IG、T1、HLE、GEN、DK 一队选手的韩服账号，按段位排序，可以直接跳转查看战绩。

## 安装与更新

从 [Releases](https://github.com/LLYY0418/Deep-Legends/releases/latest) 下载 `Deep-Legends-Setup-<版本>-public.exe`，双击安装即可。不需要管理员权限，默认安装到当前用户。

应用会自动检查新版本，有更新时在顶栏提示，点一下就能完成升级，桌面快捷方式和设置都会保留。

外服战绩通过内置中转服务查询，不需要自己申请 Riot API Key。如果有个人 Key，也可以在「设置 › 隐私与能力」里填写，填写后优先直连。

## 隐私与安全

- 只连接本机客户端（127.0.0.1），不要求 QQ 或 Riot 账号登录。
- 客户端令牌只保存在内存中，不写入日志，也不发给任何外部服务。
- 查询公开玩家时，只向固定的公开数据源（Riot 官方接口、OP.GG、腾讯官方图片域名等）发送被查询玩家的 Riot ID。
- 默认只读。写入符文、装备方案、领奖等操作都需要你主动点击；自动规则需要你逐项开启。
- 不提供合成、分解、购买等任何消费类操作。

桌面主程序会隐藏启动内置的本地数据服务，服务只监听 127.0.0.1 上的随机端口。页面与服务之间用会话令牌鉴权，令牌保存在应用数据目录的 `session-token` 文件中（文件权限 0600，目录权限 0700），用于服务重启后页面继续可用；它只用于本机鉴权，不会上传服务器。

## 从源码构建

需要 Go 1.24+、Node.js 22+，以及 Windows PowerShell。

```powershell
npm ci --prefix desktop
$riotKeyCipher = (& go run ./backend -encrypt-riot-key '<RIOT_API_KEY>').Trim()
./build-desktop-windows.ps1 -KeyMode public -RiotAPIKeyCipher $riotKeyCipher
```

产物在 `dist/desktop/`。只调试后端时：

```bash
go build ./backend
go test ./backend
node --test backend/web/*.test.cjs desktop/*.test.cjs
```

`installer/` 是独立的 Go 模块，需要单独执行 `cd installer && go test ./...`。

## 目录结构

```text
backend/     Go 本地服务、前端界面（backend/web）、内嵌数据与测试
desktop/     Electron 桌面外壳与打包配置
installer/   安装与卸载程序（独立 Go 模块）
relay/       Riot 战绩中转服务（Cloudflare Worker）
scripts/     构建、发布与 CI 辅助脚本
tools/       独立的小工具
```
