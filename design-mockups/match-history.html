实现要点（对应工单 P4–P7）

  • 网格列定义：卡片 108px | 1fr | auto | 40px（列间距 8px）；中列内部 auto | minmax(96px,auto) | auto | 1fr——英雄、KDA、数据三组以 22px 固定间距紧凑聚拢在左，末尾 1fr 吸收多余空白；数据列带左分隔线与 KDA 成组，不再飘到卡片最右。
  • 竞技场右列 128px、普通模式 190px；释放的宽度归中列。容器 ~680px 以下先收玩家名单，KDA 永不隐藏。
  • 数据列按模式取字段（对照 OP.GG）：排位/匹配 = 击杀参与率 · CS(分均) · 平均段位；极地/海克斯大乱斗 = 击杀参与率 · 伤害·承伤 · 平均段位；斗魂竞技场 = 本场名次 · 伤害·承伤；其余模式 = 击杀参与率 · CS · 伤害。统一「标签左、数值右」，左侧分隔线与 KDA 成组。
  • 小窗口生涯统计弹窗：容器查询 < 1020px 时 .career-column 移出布局（现有断点是改成两列堆叠在战绩下方，改为整列隐藏），左上角出现入口按钮；面板为覆盖内容区的底部升起式 sheet，宽度 = 内容区宽度，带 --overlay 遮罩；遮罩点击 / × / Esc 关闭，打开时给内容区加 inert，关闭后焦点回到按钮。≥1020px 时按钮与弹窗都不存在，维持现有两列布局。
  • 展开详情时右侧玩家名单保留，详情区只向下追加；名单列宽 236px（竞技场 150px），头像 20px。
  • 海克斯 3×2（26px 圆形），稀有度用描边色：棱彩紫 / 黄金金 / 白银默认；空位保留半透明占位。
  • 竞技场详情：全局列头一次 + 按名次分组，列头与行共用同一 grid template（不用独立 table），窄窗口先隐藏「装备」列再隐藏「海克斯」。
  • 队名中文映射：Poros 魄罗 / Minions 小兵 / Scuttles 河道蟹 / Krugs 石甲虫 / Raptors 锐咬鸟 / Sentinels 哨兵 / Wolves 暗影狼 / Gromp 魔沼蛙。
  • 警示条只在国服页签且 match-details capability 为 failed 时出现，展示后端返回的具体错误。
  • 更多模式菜单复用服务器选择器的视觉与键盘语义；选中后触发器文案替换为模式名。
