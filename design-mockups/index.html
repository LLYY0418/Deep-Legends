导入 Figma 的方法

  1. 在 Chrome / Edge 安装 html.to.design 浏览器扩展（divRIOTS 出品，Figma 官方社区同名插件的配套扩展）。
  2. 在本目录启动本地预览：python3 -m http.server 8400，浏览器打开 http://localhost:8400/overview.html。
  3. 点击扩展图标 → Capture current tab，把捕获结果复制到剪贴板。
  4. 在 Figma 新建文件，运行插件 html.to.design，选择 Paste from extension，页面即以可编辑图层（Frame / 文本 / 填充）导入。
  5. 其余 7 个页面重复第 2–4 步，每页一个画板；建议画板宽度 1440。

说明：皮肤原画与英雄图标引用 Riot Data Dragon 公共 CDN，联网打开即可显示；导入 Figma 时图片会一并嵌入。
