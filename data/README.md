## 完整性校验

原图检测到 140 条横向表格线，即 139 行。表格为四列，最后一行右侧两格为空，因此共有 `139 × 4 − 2 = 554` 个非空条目。逐格 OCR、中文客户端目录交叉核验和最终人工确认后，JSON 清单包含 554 个不同的普通皮肤 ID；文本文件保存最终确认的 554 行名称。

## 运行时准确性策略

公告只给中文名称，没有皮肤 ID。内置清单已将原图 554 个格子固化为稳定皮肤 ID，运行时直接核对这些 ID 是否存在于当前国服普通皮肤目录；公告名称只作审计标签，不参与差集运算。只有 554 个 ID 全部存在时，程序才计算：

```text
三合一剩余 = 奖池皮肤 ID 集合 − 当前账号已拥有皮肤 ID 集合
```

若客户端目录缺少任一稳定 ID，程序停止剩余计算并列出待核对条目，避免输出不完整或错误数字。炫彩通过目录结构、分类/父皮肤字段与 ID 范围单独排除，不能因名称近似被当作其所属普通皮肤。
