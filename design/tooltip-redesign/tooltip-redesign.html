海克斯档在做什么。黑是底、金是框和字。面板取 mix(--bg 70%, --surface)，比卡片还暗一点点；描边是主色掺 46% 进 --line，对面板有 2.2–3.7 的对比，真正撑起轮廓的是这道框；正文是 --ink 掺 28% 主色，黑金下得到 #E5D7C3 那种羊皮纸暖白。掺主色进文字安全（--ink 近中性，只会被稀释）；掺进底色会翻车 —— 金色 H≈80° 与深蓝表面 H≈264° 在 OKLab 里接近对角，彩度会被抵消掉。

和原来那根黄条的区别。原来是 border-top: 2px solid var(--primary) 顶部实色横条，外加金色四边描边和 0 0 0 1px 金色外圈，三份叠一起，浮层拿到全页最重的视觉权重。现在只剩一道均匀的 1px 描边，没有横条、没有外圈发光。

浅色为什么是纯白。八套配色实测层级亮度，浅色是 bg 1.000 / surface 0.973 / surface-strong 0.925，越往上层越亮；深色系反过来。统一规律是「层级越高越亮」，所以最上面一层在浅色下就是 #FFFFFF，靠描边和投影从白底上分离。

纯黑 OLED 下面板就是 #000000。和页面底同色，完全靠金框划出轮廓 —— 这是 OLED 下唯一不糊像素的做法，也正好最像客户端。

单行提示不上主色。「展开详情」这种只有一行的提示没有标题正文之分，标题色会让它看起来像个状态提示。data-layout="single" 下退回普通墨色。

顺手修掉一个真 bug。现在 show() 先 hidden = false 并把 left/top 设成 0，下一帧才定位，所以每次都会在视口左上角闪一帧全不透明的提示框。初始 opacity: 0 之后天然看不见。另外删掉了无效的 backdrop-filter: blur(12px)。
